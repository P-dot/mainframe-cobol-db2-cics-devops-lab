# 01 - Visión general

Este lab continúa el bloque de COBOL/JCL tras el File Transfer.

El vídeo propone tres trabajos independientes, no un único JCL grande:

```text
1. Verificar que existe un archivo.
2. Concatenar dos archivos.
3. Ordenar el resultado.
```

En el lab se reproduce esa idea con miembros de un PDS de 80 bytes:

```text
IBMUSER.COBOL.FILE80(CLIENTE1)
IBMUSER.COBOL.FILE80(CLIENTE2)
IBMUSER.COBOL.FILE80(CLIENTE3)
IBMUSER.COBOL.FILE80(CLIENTE)
```
