# 03 - Miembros de entrada y salida

```text
CLIENTE1  → datos de entrada 1
CLIENTE2  → datos de entrada 2
CLIENTE3  → salida de concatenación
CLIENTE   → salida ordenada final
```

`CLIENTE3` lo genera `CATCLI` y debe quedar con 18 registros.

`CLIENTE` lo genera `SORTCLI` y debe quedar con los 18 registros ordenados por apellido.
