# 07 - Troubleshooting: `SORTOUT NOT DEFINED`

Error observado:

```text
ICE056A SORTOUT NOT DEFINED
COND CODE 0016
```

Causa:

```jcl
//SORTIN  DD DSN=IBMUSER.COBOL.FILE80(CLIENTE3),DISP=SHR
//SORTIN  DD DSN=IBMUSER.COBOL.FILE80(CLIENTE),DISP=SHR
```

Corrección:

```jcl
//SORTIN  DD DSN=IBMUSER.COBOL.FILE80(CLIENTE3),DISP=SHR
//SORTOUT DD DSN=IBMUSER.COBOL.FILE80(CLIENTE),DISP=SHR
```
