# DB2I menu validation

The DB2I primary option menu is visible in the evidence.

The menu includes options such as:

```text
SPUFI
DCLGEN
PROGRAM PREPARATION
PRECOMPILE
BIND/REBIND/FREE
RUN
DB2 COMMANDS
UTILITIES
DB2I DEFAULTS
```

Interpretation:

- The DB2 ISPF panel environment is available.
- The user session has access to DB2 tooling.
- The DB2-aware TSO/ISPF logon procedure is working.

This is a user-level validation, complementary to the system-level SDSF address-space validation.
