# Commands and checks used

## Console / SDSF command line

```text
/D A,L
/D IPLINFO
```

## SDSF

```text
DA
```

Look for address spaces such as:

```text
D9G1MSTR
D9G1IRLM
D9GDBM1
D9GDIST
CICSA
```

## TSO/ISPF DB2 verification

Access DB2I panels from the DB2-enabled ISPF session and verify the DB2I primary option menu.

## CICS verification

Access the CICS region and confirm the CICS welcome screen.
