# Source notes

This lab is based on the user's completed ADCD/zOS practice evidence and the COBOL procedure lessons from the Universo Mainframe training sequence.

Referenced learning points:

- COBOL programs can be structured with paragraph labels.
- Paragraphs are typically named with a numeric prefix and a descriptive name.
- `PERFORM` calls a paragraph or a paragraph range.
- `PERFORM ... THRU ...` executes from a starting paragraph through an ending paragraph.
- `SYSIN` provides input data to the batch program.
- `DISPLAY` writes to `SYSOUT`.
- The JCL pattern uses `JOB`, `EXEC`, `DD`, `STEPLIB`, `SYSIN` and `SYSOUT`.
