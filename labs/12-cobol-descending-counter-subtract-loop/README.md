# Lab 12 - COBOL descending counter loop with SUBTRACT

## Objective

This lab demonstrates a controlled COBOL batch loop using a descending counter.

The program reads one line from `SYSIN`, initializes a numeric counter, repeatedly executes a COBOL paragraph with `PERFORM ... UNTIL`, decrements the counter with `SUBTRACT 1 FROM`, and writes the result to `SYSOUT`.

## Environment

- Platform: IBM z/OS ADCD 1.11 on Hercules / zPDT-style lab environment
- User: `IBMUSER`
- Source library: `IBMUSER.COBOL.SRC`
- Load library: `IBMUSER.COBOL.LOAD`
- JCL library: `IBMUSER.ML.JCL`
- Output validation: SDSF / SYSOUT

## Technical scope

This lab covers:

- COBOL paragraph-based program structure
- `PERFORM ... UNTIL`
- Numeric counter declaration with `PIC 9(02)`
- Counter initialization with `MOVE`
- Descending counter logic with `SUBTRACT ... FROM`
- Batch input using `SYSIN`
- Batch output using `SYSOUT`
- Single JCL job for compile, link-edit and execution

## Expected result

The job compiles, link-edits and executes `PARMDEC`.
The final `SYSOUT` displays one initialization line and repeated output lines generated by the descending loop.

```text
INICIO DEL PROGRAMA PARMDEC
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
MENSAJE CON CONTADOR DESCENDENTE DESDE SYSIN
```

## Professional value

This lab shows a fundamental batch programming pattern: a controlled loop with an explicit initialization, stop condition and counter update. It also highlights a common COBOL syntax distinction: `ADD ... TO` versus `SUBTRACT ... FROM`.
