# Lab 11 - DFSORT INREC BUILD and conditional OVERLAY

## Objective

Demonstrate advanced DFSORT record transformation techniques on z/OS ADCD:

- Sort customer records by customer number.
- Reformat records with `INREC BUILD`.
- Add conditional flags with `INREC IFTHEN` and `OVERLAY`.
- Validate the generated output in ISPF/SDSF.

## Environment

- Platform: IBM z/OS ADCD 1.11 on Hercules / zPDT-style lab environment
- User: `IBMUSER`
- Input PDS: `IBMUSER.COBOL.FILE80`
- Input member: `CLIENTE1`
- Output members:
  - `CLIINR` for `INREC BUILD`
  - `CLIFLG` for `IFTHEN` + `OVERLAY`
- JCL library: `IBMUSER.ML.JCL`

## Dataset members

| Member | Purpose |
|---|---|
| `CLIENTE1` | Input customer records |
| `CLIINR` | Reformatted output generated by `INREC BUILD` |
| `CLIFLG` | Flagged output generated by `IFTHEN` and `OVERLAY` |

## Jobs

| Job/member | Purpose |
|---|---|
| `INREC1` | Sorts by customer number and builds a reformatted output record |
| `INREC2` | Sorts by customer number and marks each record as `MENOR` or `MAYOR` depending on amount |

## Technical summary

### INREC BUILD

`INREC BUILD` creates a new record layout before the sort operation completes. The input file is not physically changed; DFSORT reformats records for the output pipeline.

Main control statements:

```text
SORT FIELDS=(1,7,ZD,A)
INREC BUILD=(1,7,C' ',8,12,C'-$-',36,8,C' ',28,7,C'-',DATE1)
```

This produces an output format similar to:

```text
0000010 FERNANDEZ   -$-00000190 MADRID -20260726
```

### IFTHEN + OVERLAY

`IFTHEN` applies conditional logic, while `OVERLAY` writes a value at a selected position without rebuilding the whole record.

Main control statements:

```text
SORT FIELDS=(1,7,ZD,A)
INREC IFTHEN=(WHEN=(36,8,ZD,LT,400),
              OVERLAY=(47:C'MENOR')),
      IFTHEN=(WHEN=NONE,
              OVERLAY=(47:C'MAYOR'))
```

Logic:

```text
amount < 400  -> MENOR
otherwise     -> MAYOR
```

## Validation

The evidence shows:

- `CLIINR` member created.
- `INREC1` JCL created and executed.
- `CLIFLG` member created.
- `INREC2` JCL created and executed.
- `CLIFLG` output with `MENOR` / `MAYOR` classification.
- `CLIINR` output with customer number, surname, amount, city and date.

## Professional value

This lab demonstrates batch data engineering with DFSORT: sorting, transforming layouts, inserting literals, adding system date fields, and applying conditional record annotation without writing a COBOL program.
