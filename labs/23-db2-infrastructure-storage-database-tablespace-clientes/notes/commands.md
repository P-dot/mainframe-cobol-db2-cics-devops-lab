# Commands and Execution Notes

## SPUFI panel values

Use relative dataset names in SPUFI:

```text
Input data set  ===> DB2LAB.SPUFI(member)
Output data set ===> DB2LAB.SPUFO
```

Core options:

```text
EDIT INPUT       ===> YES or NO
EXECUTE          ===> YES
AUTOCOMMIT       ===> YES
BROWSE OUTPUT    ===> YES
```

## Executed SQL sequence

### SPU001 - Inventory Storage Groups

```sql
SELECT NAME, CREATOR, VCATNAME
FROM SYSIBM.SYSSTOGROUP
ORDER BY NAME;
```

### SPU002 - Inventory Storage Group volumes

```sql
SELECT SGNAME, VOLID
FROM SYSIBM.SYSVOLUMES
ORDER BY SGNAME, VOLID;
```

### SPU003 - Reorder output to show VOLID first

```sql
SELECT VOLID, SGNAME
FROM SYSIBM.SYSVOLUMES
ORDER BY VOLID, SGNAME;
```

### SPU004 - Reorder output to show VCATNAME first

```sql
SELECT VCATNAME, NAME, CREATOR
FROM SYSIBM.SYSSTOGROUP
ORDER BY VCATNAME, NAME;
```

### SPU005 - Confirm `DB2LABSG` is free

```sql
SELECT NAME, CREATOR, VCATNAME
FROM SYSIBM.SYSSTOGROUP
WHERE NAME = 'DB2LABSG';
```

### SPU006 - Create `DB2LABSG`

```sql
CREATE STOGROUP DB2LABSG
  VOLUMES (SBDB91)
  VCAT DSN910;
```

### Verify `DB2LABSG`

```sql
SELECT VOLID, SGNAME
FROM SYSIBM.SYSVOLUMES
WHERE SGNAME = 'DB2LABSG';
```

### SPU007 - Confirm `DB2LABDB` is free

```sql
SELECT NAME, CREATOR
FROM SYSIBM.SYSDATABASE
WHERE NAME = 'DB2LABDB';
```

### SPU008 - Create `DB2LABDB`

```sql
CREATE DATABASE DB2LABDB
  STOGROUP DB2LABSG
  BUFFERPOOL BP0;
```

### SPU010 - Verify `DB2LABDB`

```sql
SELECT STGROUP, BPOOL, NAME, CREATOR
FROM SYSIBM.SYSDATABASE
WHERE NAME = 'DB2LABDB';
```

### SPU011 - Confirm `DB2LABTS` is free

```sql
SELECT NAME, DBNAME
FROM SYSIBM.SYSTABLESPACE
WHERE DBNAME = 'DB2LABDB'
  AND NAME   = 'DB2LABTS';
```

### SPU012 - Create `DB2LABTS`

```sql
CREATE TABLESPACE DB2LABTS
  IN DB2LABDB
  USING STOGROUP DB2LABSG
  PRIQTY 12
  SECQTY 12
  ERASE NO
  FREEPAGE 0
  PCTFREE 10
  BUFFERPOOL BP0
  LOCKSIZE ANY
  LOCKMAX SYSTEM
  CLOSE YES;
```

### SPU013 - Verify `DB2LABTS`

Failed attempt:

```sql
SELECT NAME, DBNAME, BPOOL, LOCKRULE, LOCKMAX, CLOSE
FROM SYSIBM.SYSTABLESPACE
WHERE DBNAME = 'DB2LABDB'
  AND NAME   = 'DB2LABTS';
```

Corrected query:

```sql
SELECT NAME, DBNAME, BPOOL, LOCKRULE, LOCKMAX
FROM SYSIBM.SYSTABLESPACE
WHERE DBNAME = 'DB2LABDB'
  AND NAME   = 'DB2LABTS';
```

### SPU014 - Confirm `IBMUSER.CLIENTES` is free

```sql
SELECT CREATOR, NAME, DBNAME, TSNAME
FROM SYSIBM.SYSTABLES
WHERE CREATOR = 'IBMUSER'
  AND NAME    = 'CLIENTES';
```

### SPU015 - Create `IBMUSER.CLIENTES`

```sql
CREATE TABLE IBMUSER.CLIENTES
 (
   DNI        CHAR(9)  NOT NULL,
   NOMBRE     CHAR(20) NOT NULL,
   APELLIDOS  CHAR(30) NOT NULL,
   DIRECCION  CHAR(35) NOT NULL
 )
 IN DB2LABDB.DB2LABTS;
```

### SPU017 - Verify table location

```sql
SELECT DBNAME, TSNAME, NAME, CREATOR
FROM SYSIBM.SYSTABLES
WHERE CREATOR = 'IBMUSER'
  AND NAME    = 'CLIENTES';
```
