# Comandos usados / útiles

## CEDA

```text
CEDA VIEW DB2CONN(CICSDB2) GROUP(ALL4)
CEDA DEFINE DB2ENTRY(ALL4) GROUP(ALL4)
CEDA DEFINE DB2TRAN(ALL4TRAN) GROUP(ALL4)
CEDA DEFINE MAPSET(ALL4MP) GROUP(ALL4)
CEDA DEFINE LIBRARY(ALL4LIB) GROUP(ALL4)
CEDA DEFINE PROGRAM(ALL4) GROUP(ALL4)
CEDA DEFINE TRANSACTION(ALL4) GROUP(ALL4)
CEDA DISPLAY GROUP(ALL4)
CEDA INSTALL GROUP(ALL4)
CEDA INSTALL MAPSET(ALL4MP) GROUP(ALL4)
CEDA INSTALL LIBRARY(ALL4LIB) GROUP(ALL4)
CEDA INSTALL PROGRAM(ALL4) GROUP(ALL4)
CEDA INSTALL TRANSACTION(ALL4) GROUP(ALL4)
CEDA INSTALL DB2ENTRY(ALL4) GROUP(ALL4)
CEDA INSTALL DB2TRAN(ALL4TRAN) GROUP(ALL4)
```

## CEMT

```text
CEMT SET PROGRAM(ALL4) NEWCOPY
CEMT SET PROGRAM(ALL4MP) NEWCOPY
CEMT INQ TASK
CEMT INQ DB2CONN
```

## CEDF

```text
CEDF
CLEAR
ALL4
```

Puntos a observar:

```text
PROGRAM INITIATION
EXEC CICS RECEIVE MAP('ALL4MP')
RESPONSE NORMAL / MAPFAIL
EXEC CICS SEND MAP('ALL4MP')
EXEC CICS RETURN TRANSID('ALL4')
```
