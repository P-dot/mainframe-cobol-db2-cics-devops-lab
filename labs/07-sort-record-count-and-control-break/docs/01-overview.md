# 01 - Visión general

El lab parte del resultado del Lab 06:

```text
CLIENTE1 + CLIENTE2 -> CLIENTE3 -> CLIENTE
```

En este lab, `CLIENTE` ya contiene 18 registros ordenados por apellido. El objetivo es usar `SORT` para:

```text
1. Contar los 18 registros.
2. Reducir duplicados por apellido.
3. Sumarizar importes.
4. Generar un archivo final de 9 registros.
```
