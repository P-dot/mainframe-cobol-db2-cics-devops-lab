# Troubleshooting

## Periods inside inline PERFORM

Incorrect:

```cobol
           PERFORM 5 TIMES
              DISPLAY 'HOLA'.
              DISPLAY 'HOLA OTRA VEZ'.
           END-PERFORM.
```

Correct:

```cobol
           PERFORM 5 TIMES
              DISPLAY 'HOLA'
              DISPLAY 'HOLA OTRA VEZ'
           END-PERFORM.
```

The period closes the inline block at `END-PERFORM`.

## RUN step cannot find STEPLIB

A previous run showed a `STEPLIB - DATA SET NOT FOUND` condition. The final working JCL uses:

```jcl
//STEPLIB DD DSN=*.BUILD.LKED.SYSLMOD,DISP=SHR
```

This lets the run step use the output generated by the link-edit step.

## Output size

The output is intentionally large. The expected business output is 122 lines:

```text
1 start line + 120 repeated message lines + 1 end line
```
