# Lab 17 - COBOL inline PERFORM and TIMES nested loops

## Objective

This lab demonstrates COBOL paragraph calls, inline `PERFORM`, `END-PERFORM`, fixed repetition with `TIMES`, and nested loop multiplication.

The program is intentionally simple: it writes messages to `SYSOUT`. The focus is the control-flow structure.

## Environment

- Platform: IBM z/OS ADCD 1.11 on Hercules / zPDT-style lab environment
- User: `IBMUSER`
- Source library: `IBMUSER.COBOL.SRC`
- Load library: `IBMUSER.COBOL.LOAD`
- JCL library: `IBMUSER.ML.JCL`
- Validation: SDSF / SYSOUT

## Technical scope

- COBOL paragraph-based structure
- Paragraph-to-paragraph `PERFORM`
- `PERFORM n TIMES`
- Inline `PERFORM ... END-PERFORM`
- Nested repetition
- JCL compile, link-edit and execution in one job
- SDSF output validation
- Runtime `STEPLIB` resolution using the link-edit `SYSLMOD`

## Program logic

```text
1000-INICIO
2000-PROCESO executed 4 times
  2100-IMPRIME-TEXTO executed 2 times
    inline PERFORM executed 5 times
      3 DISPLAY statements
3000-FIN
```

The loop multiplication is:

```text
4 x 2 x 5 x 3 = 120 display lines
```

With one start line and one end line, the expected business output is:

```text
122 lines
```

## Professional value

This lab demonstrates how COBOL can structure repeated processing through paragraphs and inline blocks. It also captures a realistic troubleshooting point: the run step can use the `SYSLMOD` generated by the build step through a backward DD reference in `STEPLIB`.
