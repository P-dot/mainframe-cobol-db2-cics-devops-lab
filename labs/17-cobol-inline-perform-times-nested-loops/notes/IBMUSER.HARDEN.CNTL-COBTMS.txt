CLASE 22 - COBOL INLINE PERFORM AND TIMES NESTED LOOPS

SOURCE:
  IBMUSER.COBOL.SRC(PARMTMS)

JCL:
  IBMUSER.ML.JCL(TMSALL)

KEY COBOL:
  PERFORM 2000-PROCESO 4 TIMES.
  PERFORM 2100-IMPRIME-TEXTO 2 TIMES.
  PERFORM 5 TIMES
     DISPLAY 'HOLA'
     DISPLAY 'HOLA OTRA VEZ'
     DISPLAY 'HOLA DE NUEVO'
  END-PERFORM.

EXPECTED OUTPUT:
  4 x 2 x 5 x 3 = 120 repeated display lines
  plus start and end messages

VALIDATION:
  TMSALL RUN executed with COND CODE 0000.
